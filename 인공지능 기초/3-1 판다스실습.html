1. 데이터 준비하기 (Import & Read)

판다스 시작하고 데이터 표로 만들기

파이썬에서 데이터를 표 형태로 다루려면 pandas라는 도구를 가져와야 합니다. 보통 줄여서 pd라고 부릅니다. 그 후, CSV(표 형태의 파일) 데이터를 읽어와서 df(데이터프레임, DataFrame)라는 이름의 변수에 저장합니다.

코드 작성 및 실행
python_code.py 
import pandas as pd

# hackathon.csv 파일을 읽어서 df라는 이름표를 붙입니다.
df = pd.read_csv('hackathon.csv')

3. 데이터 다루기 (추출과 삭제)

특정 열만 뽑아내기

표 전체에서 하나의 속성(열)만 보고 싶다면 대괄호 안에 속성명을 적어줍니다. 

df_new = df['실력']
df_new.head(3)
실력
0상
1중
2하

조건에 맞는 데이터 찾기

query()를 사용하면 조건에 맞는 행만 골라낼 수 있습니다. 

# 수면시간이 7시간 이상인 학생만 추출
df.query('수면시간 >= 7')

잠깐! 자주 헷갈리는 부분 (오개념 방지)

데이터를 삭제할 때 df.drop()을 사용합니다. 하지만 삭제 명령을 내려도 원본 데이터(df)는 스스로 변경되지 않습니다!
삭제한 결과를 저장하려면 1) 새로운 변수에 저장하거나 2) inplace=True 옵션을 꼭 써야 합니다.

원본이 안 바뀜
df.drop('영양제', axis=1)
올바른 방법
new_df = df.drop('영양제', axis=1)
df.drop('영양제', axis=1, inplace=True)

열(세로) 삭제하기

속성 전체를 지울 때는 axis=1을 적어줍니다. '영양제' 열을 지워봅시다. 

new_df = df.drop('영양제', axis=1)
new_df.head(2)
이름학년실력수면시간
0김철수1상6
1이영희2중8

행(가로) 삭제하기

특정 데이터 한 줄을 지울 때는 인덱스(번호)와 axis=0을 적어줍니다. 맨 첫번째 데이터(인덱스 0)를 지워봅시다. 

df.drop(0, axis=0, inplace=True)
df.head(2)
